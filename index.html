How to apply one

Only the owner of a work (or someone with permission to license it) can apply a licence. Put this notice with your work, in the file metadata, the page, or the release description:

© [Year] [Your name]. Licensed under KL-[CODE] 1.0 (Kalx Licences).
https://USERNAME.github.io/kalx/KL-[CODE]/
