# Kalx Licences

Free-to-use licences from Kalx Records (v1.0). Static site, no build step.

## Put it online at `https://YOURNAME.github.io/kalx/`

1. On GitHub, create a **public** repository named exactly `kalx` (lowercase).
2. Upload everything in this folder (including the `.nojekyll` file and the `KL-*` folders) to the repo's `main` branch.
3. Repo **Settings → Pages**. Under *Build and deployment*, set **Source: Deploy from a branch**, **Branch: `main`**, folder **`/ (root)`**, then Save.
4. After a minute or two the site is live at `https://YOURNAME.github.io/kalx/` and each licence is at `.../kalx/KL-BY/` etc.

The "notice to copy" on each page fills in the live address automatically.
